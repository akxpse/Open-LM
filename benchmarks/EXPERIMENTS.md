# Separate experiments (revised per user)

## A — Cloud baseline

Terra through Codex CLI plans, implements and runs visible checks on fresh fixtures, without Qwen. Save its commands, artifacts, usage and elapsed time separately. Existing cloud-only arms of the interrupted pilot are historical baseline evidence; their verification included harness-run assertions and separate Terra review. Preserve that provenance rather than relabeling it.

## B — Open LM local implementation

The current frontier host is planner, handoff author, reviewer and final verifier. Qwen3 Coder 30B through OpenCode/Ollama alone implements and runs test commands. No Terra planner/reviewer or Codex subagent participates in B. One local model at a time. Fresh fixtures match A; task, implementation, verification and repair evidence are separate.

The host launches packets, inspects logs/source, performs root-cause analysis before retries and provides corrections. A verification-only packet runs protected assertions after implementation handoff. The host does not execute the tests itself. Distinguish test pass from independent source review and from benchmark validity.

Use local-experiment.mjs for B. It never invokes a cloud CLI or executes test commands directly. Its planning packet is authored by the host, not generated by an extra cloud call. It records unknown host-token usage as null, never zero.

## Measurement boundary

Report A and B individually. Do not call B zero-cloud-cost: the frontier host's planning, handoffs and final review still consume cloud tokens. Until those are captured with comparable accounting, total savings remain unknown. No made-up token estimates.

The earlier pilot.mjs is a superseded mixed-orchestration calibration: it used Terra for B's planning/review, which is not the requested experiment. Do not rerun it as the current benchmark or use its ratio as evidence for this architecture. Likewise, recovery/regression tests on interrupted candidates are not fresh experiment results.

These initial fixtures are small and already seen during development. Repetitions, new held-out representative tasks, long context and chains remain necessary before any public numerical claim.
